## 0.1.0

Initial release.

- `ToastProvider` + `Toast` — notification queue with auto-dismiss, `data-variant`.
- `Alert` — `role="alert"` with `aria-live` control, `data-variant`.
- `Progress` — `role="progressbar"`, determinate and indeterminate modes, `--progress` CSS variable, `data-indeterminate`.
- `Spinner` — `role="status"` with `aria-busy="true"`.
- `Avatar` + `AvatarImage` + `AvatarFallback` — image with a load-state fallback, `data-status`.
- `Meter` — `role="meter"` for a value within a known range, `data-value`, `data-high`, `data-low`, `data-optimum`.
