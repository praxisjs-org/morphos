## 1.1.2

- Declares the `@morphos/core` peer dependency as a caret range (`^0.1.6`) instead of an exact
  version, so npm no longer installs a second copy or fails with a peer conflict when the Morphos
  packages are released at different patch versions.

## 1.1.1

- Requires `@praxisjs/runtime` and `@praxisjs/jsx` 0.8.1, which write boolean `aria-*` attributes as
  `"true"` and `"false"` instead of an empty attribute (or none for `false`).

## 1.1.0

- Opts into `@praxisjs/vite-plugin`'s library optimization: with vite-plugin 4.2 or later, apps compile
  these components from their sources like their own code (compiled templates, keyed lists, decorated
  fields in fast properties), so they mount about 25 to 40% faster. The published package no longer
  includes its tests.
- `ToastProvider` renders its toasts with `For` from `@praxisjs/runtime`, keyed by `id`: adding or
  dismissing a toast leaves the other toasts' elements in place instead of rebuilding them all.
- **Peer dependencies raised** to `@praxisjs/core` >=2.3.0, `@praxisjs/decorators` >=2.0.0,
  `@praxisjs/runtime` >=0.8.0 and `@praxisjs/jsx` >=0.8.0, the releases that provide `For`.

## 0.1.0

Initial release.

- `ToastProvider` + `Toast` — notification queue with auto-dismiss, `data-variant`.
- `Alert` — `role="alert"` with `aria-live` control, `data-variant`.
- `Progress` — `role="progressbar"`, determinate and indeterminate modes, `--progress` CSS variable, `data-indeterminate`.
- `Spinner` — `role="status"` with `aria-busy="true"`.
- `Avatar` + `AvatarImage` + `AvatarFallback` — image with a load-state fallback, `data-status`.
- `Meter` — `role="meter"` for a value within a known range, `data-value`, `data-high`, `data-low`, `data-optimum`.
