## 0.1.0

Initial release.

- `Dialog` + `DialogTrigger` + `DialogContent` + `DialogTitle` + `DialogDescription` + `DialogClose` — focus trap, scroll lock, `data-open`.
- `AlertDialog` + `AlertDialogTrigger` + `AlertDialogContent` + `AlertDialogTitle` + `AlertDialogDescription` + `AlertDialogAction` + `AlertDialogCancel` — confirmation dialog requiring an explicit action or cancel, `data-open`.
- `Drawer` + `DrawerTrigger` + `DrawerContent` + `DrawerTitle` + `DrawerDescription` + `DrawerClose` — slide-in panel anchored to a viewport edge, `data-open`, `data-side`.
- `Tooltip` + `TooltipTrigger` + `TooltipContent` — hover/focus intent with configurable delays.
- `Popover` + `PopoverTrigger` + `PopoverContent` — click toggle, outside-click dismiss, `data-open`.
- `Dropdown` (aliased `Menu`) + `DropdownTrigger` + `DropdownMenu` + `DropdownItem` — keyboard navigation (arrow keys, Home, End, Escape), `role="menu"`.
- `ContextMenu` + `ContextMenuTrigger` + `ContextMenuContent` + `ContextMenuItem` — right-click-triggered menu, `data-open`.
- `PreviewCard` + `PreviewCardTrigger` + `PreviewCardContent` — hover-triggered rich preview, `data-open`.
