## 1.1.0

- `ScrollArea` — added `scrollTo({ top?, left? })` to imperatively scroll the viewport, clamped to the valid scroll range.
- `ScrollAreaScrollbar` — clicking the track now jumps the scroll position to the clicked location, matching native scrollbar track-click behavior.
- `ScrollAreaThumb` — the thumb is now actually draggable, not just visually sized/positioned.

## 0.1.0

Initial release.

- `Accordion` + `AccordionItem` + `AccordionTrigger` + `AccordionContent` — single/multiple mode, collapsible, `data-expanded`.
- `Tabs` + `TabList` + `Tab` + `TabPanel` — horizontal/vertical keyboard navigation (arrow keys, Home, End), `data-selected`.
- `Disclosure` (aliased `Collapsible`) + `DisclosureTrigger` + `DisclosureContent` — simple show/hide toggle, `data-open`.
- `Separator` — decorative or semantic divider, `data-orientation`.
- `ScrollArea` + `ScrollAreaViewport` + `ScrollAreaScrollbar` + `ScrollAreaThumb` — custom scrollbar over native scrolling, proportionally sized thumb, `data-orientation`, `data-type` (including a `"hidden"` mode that keeps native scrolling without ever showing the custom scrollbar), `data-scrollable`.
- `Toolbar` + `ToolbarButton` + `ToolbarSeparator` — roving-tabindex button group, `data-orientation`.
- `Menubar` + `MenubarMenu` + `MenubarTrigger` + `MenubarContent` + `MenubarItem` + `MenubarSeparator` — horizontal bar of menus with outside-click and Escape dismissal, `data-open`.
- `NavigationMenu` + `NavigationMenuList` + `NavigationMenuItem` + `NavigationMenuTrigger` + `NavigationMenuContent` + `NavigationMenuLink` — top-level site navigation with hover/focus-driven submenus that close on outside click or Escape, `data-active`, `data-orientation`.
