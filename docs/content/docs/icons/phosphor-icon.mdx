## Installation

<PackageInstall pkg="@morphos/icons" />

`PhosphorIcon` renders assets from [Phosphor](https://phosphoricons.com) — install the icon
catalog separately in your app:

```sh
npm install @phosphor-icons/core
```

<Callout type="info">
  `@morphos/icons` does not depend on `@phosphor-icons/core`. `PhosphorIcon` accepts any raw
  `<svg>` string, so you bring your own version of the icon set.
</Callout>

## Import

```ts
import { PhosphorIcon } from '@morphos/icons'
```

## Usage

Phosphor ships each icon as a `.svg` file per weight. Import it as raw text — with Vite, append
`?raw`:

```tsx
import plusRegular from '@phosphor-icons/core/assets/regular/plus.svg?raw'
import { PhosphorIcon } from '@morphos/icons'

<PhosphorIcon svg={plusRegular} aria-label="Add item" />
```

Pick the weight (`thin`, `light`, `regular`, `bold`, `fill`, `duotone`) by choosing which asset
path you import — `PhosphorIcon` itself is weight-agnostic, it just renders whatever markup it's given.
Every weight except `regular` suffixes the filename:

```tsx
import plusBold from '@phosphor-icons/core/assets/bold/plus-bold.svg?raw'
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `svg` | `string` | — | Raw SVG markup for one weight |
| `size` | `number \| string` | `24` | Applied to both `width` and `height` |
| `color` | `string` | — | Sets the SVG `color` attribute, which the asset's `fill="currentColor"` resolves against |
| `mirrored` | `boolean` | `false` | Flips the icon horizontally |
| `style` | `string \| CSSProperties` | — | Inline style on the root `<svg>` |
| `class` | `string` | — | CSS class on the root `<svg>` |
| `id` | `string` | — | `id` on the root element |
| `aria-label` | `string` | — | Accessible name. When set, the icon gets `role="img"`; otherwise it's `aria-hidden` |

## Accessibility

Icons are decorative by default: `aria-hidden="true"` and no `role`. Pass `aria-label` when the
icon conveys meaning on its own — `PhosphorIcon` then switches to `role="img"` with that label.
