## Usage

`Icon` renders any raw SVG markup — a full `<svg>...</svg>` string or bare inner markup — sized
and colored through props. It's the shared rendering foundation behind `LucideIcon` and
`PhosphorIcon`, and the escape hatch for any other icon set (Heroicons, Feather, an in-house
sprite sheet, ...).

```tsx
<Icon svg='<path d="M5 12h14"/><path d="M12 5v14"/>' aria-label="Add" />
```

When `svg` is a full `<svg>` string, its `viewBox` is read automatically and the outer tag is
stripped:

```tsx
import plusRegular from '@phosphor-icons/core/assets/regular/plus.svg?raw'

<Icon svg={plusRegular} size={20} />
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `svg` | `string` | — | Full `<svg>...</svg>` markup (its `viewBox` is read and the tag stripped) or bare inner markup |
| `viewBox` | `string` | `"0 0 24 24"` | Used when `svg` is bare inner markup and carries no `viewBox` of its own |
| `size` | `number \| string` | `24` | Applied to both `width` and `height` |
| `color` | `string` | — | Sets the SVG `color` attribute, which `currentColor` fills/strokes resolve against |
| `style` | `string \| CSSProperties` | — | Inline style on the root `<svg>` |
| `class` | `string` | — | CSS class on the root `<svg>` |
| `id` | `string` | — | `id` on the root element |
| `aria-label` | `string` | — | Accessible name. When set, the icon gets `role="img"`; otherwise it's `aria-hidden` |

## Accessibility

Icons are decorative by default: `aria-hidden="true"` and no `role`. Pass `aria-label` when the
icon conveys meaning on its own (for example, an icon-only button with no visible text) — `Icon`
then switches to `role="img"` with that label instead of hiding itself.

<Callout type="info">
  If the icon sits next to visible text that already describes it, leave `aria-label` unset so
  screen readers don't announce the same thing twice.
</Callout>
