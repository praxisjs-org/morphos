## Installation

<PackageInstall pkg="@morphos/icons" />

`LucideIcon` renders data from [lucide](https://lucide.dev) — install it separately in your app:

```sh
npm install lucide
```

<Callout type="info">
  `@morphos/icons` does not depend on `lucide`. `LucideIcon` accepts any data shaped like lucide's
  `[tag, attrs][]` icon-node format, so you bring your own version of the icon set.
</Callout>

## Import

```ts
import { LucideIcon } from '@morphos/icons'
```

## Usage

```tsx
import { Plus } from 'lucide'
import { LucideIcon } from '@morphos/icons'

<LucideIcon icon={Plus} aria-label="Add item" />
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `icon` | `IconNode` | — | Icon node data, e.g. `import { Plus } from "lucide"` |
| `size` | `number \| string` | `24` | Applied to both `width` and `height` |
| `color` | `string` | `"currentColor"` | Sets `stroke` |
| `strokeWidth` | `number \| string` | `2` | Stroke thickness |
| `absoluteStrokeWidth` | `boolean` | `false` | Scales `strokeWidth` so the visual stroke thickness stays constant across sizes |
| `class` | `string` | — | CSS class on the root `<svg>` |
| `id` | `string` | — | `id` on the root element |
| `aria-label` | `string` | — | Accessible name. When set, the icon gets `role="img"`; otherwise it's `aria-hidden` |

`IconNode` is exported for typing your own data: `readonly (readonly [tag: string, attrs:
Record<string, string | number | undefined>])[]` — structurally identical to lucide's own
`IconNode` type, so icons imported straight from the `lucide` package are accepted as-is.

## Accessibility

Icons are decorative by default: `aria-hidden="true"` and no `role`. Pass `aria-label` when the
icon conveys meaning on its own — `LucideIcon` then switches to `role="img"` with that label.

## Sizing the stroke consistently

By default, thicker strokes look proportionally heavier on smaller icons. Set
`absoluteStrokeWidth` to keep the rendered stroke thickness constant regardless of `size`:

```tsx
<LucideIcon icon={Plus} size={16} strokeWidth={2} absoluteStrokeWidth />
```
