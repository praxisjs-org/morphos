Initial release. New package for bringing your own icon set: `Icon` (generic SVG primitive for
raw markup), `LucideIcon` (renders `lucide` package icon data), and `PhosphorIcon` (renders raw
SVG assets from `@phosphor-icons/core`). Neither `lucide` nor `@phosphor-icons/core` is a
dependency — install whichever icon set you use in your own app.
